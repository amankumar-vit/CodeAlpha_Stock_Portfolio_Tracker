# Stock Portfolio Tracker 

This is a Python-based project developed during my CodeAlpha Internship.

# Objective
The goal of this project is to calculate total investment value based on user input of stocks and quantities.

# Features
- User inputs stock name and quantity  
- Predefined stock prices used  
- Calculates total investment value  
- Saves result in a text file  

# Technologies Used
- Python  
- Dictionary  
- Loops & Conditions  
- File Handling  

# How to Run
1. Run the Python file  
2. Enter stock name (AAPL, TSLA, etc.)  
3. Enter quantity  
4. Type "done" to finish
